# Al Falah Islamic Academy Website

Responsive React + Vite website with the supplied official academy logo.

## Included
- Home, About, Courses, Admissions and Contact sections
- Five academy courses: Tajweed, Tafsir, Tarjuma + Tafsir, Seerah of Prophets and Hifz
- WhatsApp enquiry form addressed to +91 98419 94420
- Responsive mobile navigation

## Run locally
Install Node.js, then run:

```bash
npm install
npm run dev
```

Open the local address printed by Vite (normally http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

The production files are created in `dist/`.

## WhatsApp note
The form prepares a WhatsApp message with the student's answers. The visitor must review and press Send. No email service, paid form provider, or backend is used.
